# log-io - Documentation

Reference documentation for the `log-io` crate. Rustdoc on
[docs.rs/log-io](https://docs.rs/log-io) is authoritative for
signatures; these documents explain how the pieces fit together.

## Documents

- [API Reference](./API.md) - every component, with runnable examples
  (each one is compiled and run as a doctest).
- [Migration Guide](./MIGRATION.md) - upgrading from 1.x to 2.0.
- [Release notes](./release/) - one file per release.
- [Benchmarks](../BENCH.md) - method, machine and measured numbers.
- [Specification](../REPS.md) - API contract, safety, MSRV, stability
  and dependency policies.
- [Changelog](../CHANGELOG.md) - every change, by version.
- [Fuzzing](../fuzz/README.md) - fuzz targets and how to run them.
